# 🍵 Sonsuz Çay Kaşığı Ölçümü

## Bu Repo Nedir?

Bu, insanlık tarihinin en büyük bilimsel atılımıdır. Çay kaşığıyla evrenin boyutlarını ölçen, sürekli dönen, hiçbir işe yaramayan, ama **gerçekten çalışan** efsanevi bir program.

### Neden Var?

Çünkü birileri "acaba çay kaşığı kaç evren eder?" diye sordu ve biz de "haydi ölçelim" dedik. Sonuç: Sonsuz.

### Nasıl Çalışır?

1. Programı çalıştır.
2. Çay kaşığını hayal et.
3. Evreni ölçmeye başla.
4. Sonsuza kadar devam et.
5. Hiçbir şey olmasın, ama olsun.

### Özellikler

- **Yavaşlık**: Dünyanın en yavaş ölçümü. Her ölçüm 3-7 saniye sürer.
- **Felsefi Derinlik**: Her ölçümde varoluşsal bir kriz üretir.
- **Güvenilirlik**: %100 çalışır, %0 işe yarar.
- **Türkçe**: Tamamen Türkçe, çünkü çay Türk işidir.

### Kurulum

```bash
python cay_kasigi.py
```

Hepsi bu. Başka hiçbir şey yok.

### Uyarı

Bu programı çalıştırdıktan sonra çay içme arzunuz artabilir. Sorumluluk kabul etmiyoruz.

### Katkıda Bulunma

Lütfen katkıda bulunmayın. Bu program mükemmeldir. Bozmayın.
